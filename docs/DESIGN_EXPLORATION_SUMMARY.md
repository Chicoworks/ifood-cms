## 📊 Framework Simples de Decisão

Responda rápido para saber sua abordagem ideal:

### Pergunta 1: Quanto de Mudança?
```
[ ] Pouca (só ajustes, 20-30%)
[ ] Moderada (novo visual, 50%)
[ ] Significativa (redesign, 80%)
[ ] Completa (tudo novo, 100%)
```

### Pergunta 2: Qual Sensação?
```
[ ] Corporativo & Profissional
[ ] Moderno & Sofisticado
[ ] Energético & Playful
[ ] Elegante & Premium
```

### Pergunta 3: Qual Elemento Incomoda Mais?
```
[ ] Cores (muito cinzento)
[ ] Espaço (muito vazio)
[ ] Animações (muito estático)
[ ] Tipografia (muito neutra)
[ ] Cards (muito genéricos)
```

### Resultado Automático:

**Se Pouca Mudança + Energético + Cores:**
→ Abordagem 1 (Clean + Personality)

**Se Moderada Mudança + Sofisticado + Geral:**
→ Abordagem 2 (Modern Sophisticated)

**Se Significativa Mudança + Energético + Múltiplos:**
→ Abordagem 3 (Playful / Food-Focused)

**Se Moderada/Pouca + Corporativo:**
→ Abordagem 4 (Corporate Premium)
