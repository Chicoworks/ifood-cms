### Pergunta 2.2: Layout & Cards
**Como você prefere que os cards sejam?**

**OPÇÃO A: Atual (Minimalista)**
```
┌─────────────────┐
│ Título          │
│ Descrição       │
│ Status • 2h     │
└─────────────────┘
```
Características:
- Fundo cinza claro (#F5F5F5)
- Border fino gris
- Shadow mínimo
- Muito espaço vazio

---

**OPÇÃO B: Com Mais Definição**
```
┌─────────────────┐
│ ╔═ Categoria ═╗ │  ← Accent color
│ │ Título      │ │
│ │ Descrição   │ │  ← Background mais definido
│ │ Status • 2h │ │
│ ╚═════════════╝ │
└─────────────────┘
```
Características:
- Card com accent bar/border colorido
- Background mais "presente"
- Shadow um pouco mais pronunciado
- Melhor definição visual

---

**OPÇÃO C: Com Ícones & Visual**
```
┌──────────────────┐
│ 📄 Título        │  ← Ícone/emoji
│                  │
│ Descrição breve  │  ← Ilustração pequena
│                  │
│ Status • 2h      │
└──────────────────┘
```
Características:
- Ícones representativos
- Pequenas ilustrações
- Mais visual, menos texto
- Mais "divertido"

---

**OPÇÃO D: Cards Estilo Bento (Variado)**
```
┌────────┐ ┌──────────────┐
│ Página │ │ Título       │
│ Card   │ │ Descrição    │
├────────┤ │ Status • 2h  │
│ Stat   │ └──────────────┘
│ Card   │
└────────┘
```
Características:
- Diferentes tamanhos/propósitos
- Cards com layout diferente
- Bento grid mais visual
- Hierarquia clara por tamanho
