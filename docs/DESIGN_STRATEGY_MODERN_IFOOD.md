## 2️⃣ Estratégia de Cores iFood

### Cores Primárias
```
Vermelho iFood:     #EB0033 (protagonista)
Vermelho escuro:    #C40000 (hover, ativa)
Amarelo iFood:      #FBC70A (complementar, destaque)
```

### Cores Secundárias (Moderno + Pro)
```
Background escuro:  #0F0F0F ou #1a1a1a (sofisticado)
Background claro:   #FFFFFF (limpo)
Grays:              #666666, #999999, #D0D0D0 (hierarquia)
```

### Paleta Conectada
```
Dark theme base + Vermelho + Amarelo iFood
OU
Light theme base + Vermelho + Amarelo iFood
```

## 3️⃣ Estrutura Geral Proposta

### Layout Macro
```
┌──────────────────────────────────────┐
│     SIDEBAR     │      MAIN CONTENT   │
│                 │                     │
│  - Logo iFood   │  [Header/Hero]      │
│  - Nav Items    │  [Content Area]     │
│  - Footer User  │  [Componentes]      │
│                 │                     │
└──────────────────────────────────────┘
```

### Sidebar (Redesenho)
- Logo iFood grande/visível
- Nav items com cores (vermelho para ativo)
- Espaço generoso
- Footer com user info
- Tudo conectado ao design iFood

### Main Content
- Header com greeting (tipografia forte)
- Hero section (se necessário)
- Content grid (cards bem-definidos)
- Components claros e modernos

## 4️⃣ Design System Modern Pro

### Tipografia
```
Extra Large:  48px / 700 (hero, titles)
Large:        32px / 700 (headings)
Medium:       20px / 600 (subheadings)
Regular:      16px / 500 (body)
Small:        14px / 500 (labels)
Tiny:         12px / 400 (metadata)
```

### Spacing (4px grid)
```
xs:   4px
sm:   8px
md:   16px (default)
lg:   24px
xl:   32px
2xl:  48px
```

### Components Premium
```
Buttons:     Com gradientes iFood (Vermelho + Amarelo)
Cards:       Subtle shadows, borders finos
Inputs:      Vermelho on focus
Status:      Cores semânticas (verde, amarelo, vermelho)
Badges:      Cores iFood
```
